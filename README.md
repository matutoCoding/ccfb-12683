# 射线检测成像仿真与工艺校验系统（DR-RT SIM）

浏览器内运行的铸钢承压件 DR 数字射线检测工艺仿真与校验工具。TypeScript + WebGL2，**零后端、零重型第三方库**，
车间内网可直接 `npm run build` 后用静态服务器打开，全部数据在浏览器本地留底并可导出归档。

## 启动

```bash
npm install
npm run dev        # 开发
npm run test       # 公式引擎手算对账测试（26 项）
npm run build      # 类型检查 + 生产构建，产物在 dist/
```

## 六个页面与需求对照

| 工艺参数 | 射线机/探测器设备卡（焦点、像元、坏像素）；钢铝钛铜衰减系数库、HVL/TVL 随查随用、两试块反推等效 μ、CSV 导出；环缝/纵缝透照次数与布片；工艺单版本留痕 |
| 透照布置 | 原生 WebGL2 三维场景，源/探测器拖拽，焦距、L1/L2、放大倍数、偏透角实时计算；Ug 超标标红并禁止保存；双壁双影椭圆开口间距校验；筒体展开布片图 |
| 成像仿真 | 逐像素指数衰减 + 厚度分档散射 + 焦点半影几何模糊 + 泊松-高斯噪声；黑度计探头逐点读数；沿焊缝黑度剖面曲线；超黑度限值区段染色；暗场/增益/坏点插值/多帧平均校正前后并排；计算依据弹窗留底 |

## 标准公式引擎（src/core，纯 TypeScript，与 UI 解耦）

这是系统最关键的部分，全部公式集中在 `src/core/`，每个函数带推导注释，并有 26 项单测与手算值对账。

1. **几何不清晰度** `geometry.ts`
   `Ug = d·L2/L1 = d·(M−1)`，`M = F/L1`；几何模糊与运动模糊分别折算像素给出。
2. **衰减与黑度** `attenuation.ts` / `imaging.ts`
   - 直接辐射 `Id = I0·exp(−μt/10)`，散射 `I = (1+n)Id`，n 按厚度分档；
   - 胶片 H&D 特性曲线 `D = Dref + G·lg(E/Eref)`；DR 等效黑度 `D = D0 − lg(I/I0)`，与胶片同口径，可直接对标准 1.8~4 限值；
   - 主因对比度 `C = μΔt/[10(1+n)]`，管电压升高 μ 下降、对比度下降（寻优页曲线已验证单调）；
   - 两试块反推 `μ = 10·ln10·(D1−D2)/[G·(t2−t1)]`，单测可往返还原。
3. **环缝透照次数** `exposure.ts`（NB/T 47013.2 / GB/T 3323 体系）
   - 外透法：`θ=arccos[(1/K²−1+F/Do)/(F/Do)]`，`η=arcsin[(Do/2F)sinθ]`，`N=ceil(180/η)`；
   - 内透中心法：`θ=arccos(1/K)`，`N=ceil(180/θ)`；
   - 内透偏心法（偏移≥2T）：`cosβ=(F+T)/(F+KT)`；近中心（偏移<2T）自动归中心法避免薄壁区公式不连续；
   - 纵缝 `N=ceil(L/Le)`，搭接标记 20mm。所有中间角、弧长、搭接量写入 derivation 展示给工艺员核对。
4. **标准限值** `standards.ts`：NB/T 47013.2 A/AB/B 三级 Ug 分档表与黑度区间，界面可编辑另存厂内标准。

测试里的期望值均为可独立手算/正弦定律复算的值（例如外透 Do=1000、F=1200、K=1.03 → θ=17.79°、η=7.32°、N=25），
不是凭记忆的表值。改任何公式后 `npm run test` 必须全绿才能签工艺单。

## 数据与留底

- 持久化：localStorage 分表（工件/设备/系数/工艺/报告），键名带版本命名空间；
- 种子设备/工件使用**固定 ID**，store 启动时修复悬空外键，避免刷新后工艺单找不到设备；
- 工艺单每次修改追加 history 快照，报告每次修订追加 versions，旧记录只增不改；
- 台账与衰减系数表可导出 JSON/CSV 归档，仿真依据弹窗列出 μ、HVL、TVL、n、Ug、限值等全部中间量。

## 当前边界（上线前需工艺侧确认）

1. **STEP 抽壳**：完整 B-rep 抽壳需 OpenCASCADE 几何内核（数十 MB WASM），本系统对筒体/平板/管类承压件按公称几何
   精确量壁厚，STL 网格走射线求交；异形铸件的变截面壁厚当前支持在明细表手动覆盖，后续如需全自动可集成 opencascade.js。
2. **衰减系数**：内置表为 NIST XCOM 质量衰减系数结合多色等效能量的工程值，已与教材钢的 HVL 经验值核对，
   但各厂射线机能谱不同，**正式工艺单应以两试块反推值复核后写入**（界面已提供反推与留底功能）。
3. **Ug 限值表**按 NB/T 47013.2-2015 常用值内置并可编辑；若客户执行其他标准，在标准管理里改表即可，公式引擎不动。
4. 仿真图为工艺验证用的物理趋势仿真，不替代实际拍片的像质计（IQI）灵敏度判定，上线参数仍需首件实拍确认。
